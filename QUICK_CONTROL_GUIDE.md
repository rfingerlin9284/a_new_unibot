# ⚡ QUICK CONTROL GUIDE - Rick + Hive Always Running

**All commands through:** `Ctrl+Shift+B` → Select from task list

---

## 🎬 THE 4 ESSENTIAL TASKS

### **1️⃣ START (Morning)**
```
Ctrl+Shift+B → "🟢 START EVERYTHING (Rick + Hive Mind + Dashboard)"
```
✅ Rick (Ollama) starts  
✅ Hive Mind (Engine) starts  
✅ Dashboard opens (3-pane tmux)  
✅ Everything running & monitoring  

---

### **2️⃣ VIEW (During Trading)**
```
Ctrl+Shift+B → "🎮 OPEN DASHBOARD ONLY (Rick + Hive already running)"
```
✅ Opens tmux dashboard (if closed)  
✅ Assumes Rick + Hive already running  

---

### **3️⃣ CHECK (Anytime)**
```
Ctrl+Shift+B → "🐝 HIVE STATUS: Check Trading Engine Status"
```
✅ Verifies Rick running  
✅ Verifies Hive Mind running  
✅ Shows process list  

---

### **4️⃣ STOP (End of Day)**
```
Ctrl+Shift+B → "🛑 STOP EVERYTHING (Rick + Hive + Dashboard)"
```
❌ Stops Rick  
❌ Stops Hive Mind  
❌ Closes dashboard

## 🎮 IN-DASHBOARD COMMANDS

Type in **BOTTOM-RIGHT terminal** (while dashboard running):

```
> start                    Start trading
> stop                     Stop trading
> status                   Check if running
> positions                List open positions
> log I see momentum       Add note to system
> help                     Show all commands
> exit                     Exit terminal
```
